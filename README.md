# 🦉 AgenticLex

**Learn the language of agentic coding.** A friendly, device-only iOS app that
helps non-native English speakers master the English vocabulary of agentic
coding tools (Claude Code, MCP, sub-agents, hooks, skills, and more) — with
audio, spaced-repetition quizzes, and a purple owl named Lexi.

📱 **On the App Store:** https://apps.apple.com/app/agenticlex/id6771639472

> Internal code name: **ClaudeCodeLex** (Xcode target & paths). The public
> product name is **AgenticLex**.

---

## Why it exists

If you use AI coding tools but English isn't your first language, the docs and
the community speak a dialect of their own — *"add a PreToolUse hook"*, *"spin up
a sub-agent"*, *"register an MCP server"*. AgenticLex teaches that vocabulary in
5-minute sessions, keeping the **English term as the always-visible learning
anchor** and your native language as gentle scaffolding.

## Principles

- 🔊 **Audio-first** — every screen is one tap from hearing the word.
- 🧘 **Calm, never anxious** — wrong answers get a warm hug, not a red X.
- 🔒 **Device-only** — **zero servers, zero tracking, zero analytics SDKs.**
  All learning data stays on your device. BYOK (bring-your-own-key) AI features
  talk directly from your device to the provider you choose; your key lives in
  the iOS Keychain and is never sent anywhere else.
- 🌍 **7 languages** — English · 繁體中文 · 简体中文 · 日本語 · 한국어 · Español · Português.

## Build it yourself

The Xcode project is generated by [XcodeGen](https://github.com/yonyz/XcodeGen)
from `project.yml` (the source of truth; `.xcodeproj` is a derived artifact and
is git-ignored).

```bash
brew install xcodegen          # once
xcodegen generate              # regenerate ClaudeCodeLex.xcodeproj
open ClaudeCodeLex.xcodeproj   # then ⌘R
```

To build for a physical device, set your own Apple Developer Team ID in
`project.yml` (`DEVELOPMENT_TEAM: YOUR_TEAM_ID`). Simulator builds need no
signing. iOS 16+, SwiftUI.

## Contributing — especially translations 🌐

The dictionary lives in `ClaudeCodeLex/Resources/terms.*.json`. The English
master (`terms.en.json`) is canonical; each locale file holds translations with
a `status` of `verified` (reviewed by a native speaker) or `ai` (machine
translation awaiting review). **We'd love native-speaker help turning `ai`
translations into `verified` ones.** See [CONTRIBUTING.md](./CONTRIBUTING.md).
