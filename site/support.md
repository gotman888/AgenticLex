## Frequently asked

**Is AgenticLex really free?**
Yes — free forever, with no ads and no locked features. The optional Tip Jar is
purely a way to say thanks.

**What is "AI Boost"?**
An optional upgrade. If you have your own API key from OpenAI, ElevenLabs,
Anthropic, or Google, you can paste it in Settings → AI Boost to unlock more
natural cloud voices and a chat feature ("Ask Lexi"). Keys are stored only in
the iOS Keychain and are never sent to us — we have no servers. See the
[Privacy Policy](privacy) for details.

**Do I need an API key to use the app?**
No. Every core feature — the dictionary, quizzes, Listen Mode, and the built-in
voice — works fully offline and free, with no key.

**The pronunciation voice sounds robotic.**
The free voice is the built-in iOS text-to-speech engine. For more natural
voices, add an OpenAI or ElevenLabs key under AI Boost (you pay that provider
directly for usage).

**How do I reset my progress?**
Settings → Reset all progress. This cannot be undone.

**I found a wrong translation, or want to suggest a term.**
Please email us — the dictionary grows with community input.
