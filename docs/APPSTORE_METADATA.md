## Notes to Reviewer（App Review Information，英文，可直接貼）

```
AgenticLex is an offline vocabulary-learning app for non-native English speakers who use AI coding tools.

• No backend. No analytics, telemetry, or third-party SDKs. All data stays in the app sandbox.
• No account, login, email, or password — the app is fully functional on first launch.
• "AI Boost" is an OPTIONAL Bring-Your-Own-Key (BYOK) feature. A user may paste their own API key (e.g. OpenAI, ElevenLabs, Anthropic) to unlock premium text-to-speech voices and an AI chat tutor. Keys are stored only in the iOS Keychain on-device and are used to call the provider directly from the device. AgenticLex operates no server and never receives the keys or the request traffic. The app works fully without entering any key.
• The tip jar uses StoreKit 2 consumable IAPs. Tips are purely voluntary and unlock no content or features.
• "Claude Code", "Cursor", and "Cline" are referenced descriptively (nominative fair use). A trademark disclaimer appears in onboarding and in the app description. AgenticLex is independent and unaffiliated.

Test account: not required.
```

## 上架 Q&A (Apple review 可能會問)

| Q | A |
|---|---|
| Why mention "Claude Code" if you're not affiliated? | Nominative fair use. We describe vocabulary used by Claude Code users; we don't claim to be Claude Code. Trademark disclaimer prominent in onboarding & settings. |
| Why is some content English-only? | "MCP", "JSON", "API" are universally used in English even in localized engineering culture. We respect that. |
| Do you use any third-party SDKs? | No. 100% native Apple frameworks. AVFoundation for TTS, SwiftUI for everything else. |
| Where is user data stored? | Locally only, in the app sandbox. No network calls except the optional BYOK requests, which go device-to-provider directly. No analytics. |
| What is "AI Boost" / BYOK? | Optional. Users may add their own provider API key to unlock premium TTS and an AI tutor. Keys live only in the Keychain; AgenticLex has no backend and never sees them. The app is fully usable without it. |
| What's the business model? | Free forever. Optional voluntary tip jar (StoreKit 2 consumable IAP), already included. No paid tiers, no subscriptions. |
